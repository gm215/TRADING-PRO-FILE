            الفاتورة الضريبية

            بيانات شركتك (الاسم والرقم الضريبي) غير مكتملة، وتظهر فارغة في الفاتورة.

            بيانات الفاتورة

            فاتورة عادية بدون ضريبة وبدون رقم ضريبي للعميل، بترقيم منفصل (CI-)، ولا تدخل في التقرير الضريبي.

            الأصناف (فاتورة مستقلة)

            تظهر في الفاتورة بيانات شركتك وبيانات العميل فقط، بدون المورّد أو السائق أو التريلا. الأصناف والأسعار تؤخذ من الشحنة، وتعدّلها من زر «تعديل الشحنة».

            أدوات التاجر

            تكتب سعر LME مرة كل يوم (أو متى تغيّر)، ويُستعمل في حاسبة السعر وفي قيمة المخزون. الحد الأدنى بالعملة الأساسية، وينبّهك قبل حفظ شحنة ربحها أقل منه.

            في وضع الموظف تختفي أسعار الشراء والأرباح والتقارير وديون الموردين، ويبقى تسجيل الشحنات وأذون التسليم والفواتير. للخروج يُطلب الرمز. هذا قفل على هذا الجهاز فقط، وليس حساباً منفصلاً بصلاحيات.

            الشعار والختم

            ارفع صورة الختم (يُفضّل PNG بخلفية شفافة) بدون تاريخ مكتوب فيه. يظهر تلقائياً في الفواتير وأذون التسليم وعروض الأسعار والكشوف والتقارير.

            العملة الأساسية للتقارير

            أسعار الصرف مقابل 1 دولار

            الدرهم والريال السعودي والقطري والعماني والدينار البحريني مربوطة بالدولار، والقيم الافتراضية هي الأسعار الرسمية. الدينار الكويتي غير مربوط بالدولار وحده، فحدّث سعره من وقت لآخر.

            خطوات الإعداد (مرة واحدة)
            1. ادخل console.firebase.google.com وأنشئ مشروعاً جديداً.
            2. من Build ثم Authentication اضغط Get started وفعّل Email/Password (وPhone إن أردت الدخول بالهاتف).
            3. في Authentication ثم Settings ثم Authorized domains أضف نطاق موقعك على Netlify.
            4. من Build ثم Firestore Database أنشئ قاعدة بيانات، ثم من تبويب Rules الصق القواعد أدناه واضغط Publish.
            5. من Project settings ثم Your apps أضف تطبيق Web، وانسخ محتوى firebaseConfig والصقه هنا.
            rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function signedIn() { return request.auth != null; }
    function staffPath() { return /databases/$(database)/documents/staff/$(request.auth.uid); }
    function isStaffOf(owner) { return signedIn() && exists(staffPath()) && get(staffPath()).data.owner == owner && get(staffPath()).data.active == true; }
    function roleIn(owner, roles) { return isStaffOf(owner) && get(staffPath()).data.role in roles; }
    function isOwner(owner) { return signedIn() && request.auth.uid == owner; }
    function member(owner) { return isOwner(owner) || isStaffOf(owner); }
    function office(owner) { return isOwner(owner) || roleIn(owner, ['accountant']); }
    function sales(owner) { return isOwner(owner) || roleIn(owner, ['accountant', 'sales']); }

    match /staff/{uid} {
      allow read: if signedIn() && (request.auth.uid == uid || resource.data.owner == request.auth.uid);
      allow create: if signedIn() && request.auth.uid != uid && request.resource.data.owner == request.auth.uid;
      allow update: if signedIn() && resource.data.owner == request.auth.uid && request.resource.data.owner == request.auth.uid;
      allow delete: if signedIn() && resource.data.owner == request.auth.uid;
    }
    match /users/{owner} {
      match /shipments/{id} { allow read, create, update: if member(owner); allow delete: if isOwner(owner); }
      match /shipsale/{id} { allow read, create, update: if sales(owner); allow delete: if isOwner(owner); }
      match /shipfin/{id} { allow read, create, update: if office(owner); allow delete: if isOwner(owner); }
      match /oldinv/{id} { allow read, create, update: if office(owner); allow delete: if isOwner(owner); }
      match /quotes/{id} { allow read, create, update: if sales(owner); allow delete: if isOwner(owner); }
      match /customers/{id} { allow read: if member(owner); allow create, update: if sales(owner); allow delete: if isOwner(owner); }
      match /photos/{id} { allow read, create, update: if member(owner); allow delete: if isOwner(owner); }
      match /settings/{id} { allow read: if member(owner); allow write: if isOwner(owner); }
      match /counters/{id} { allow read, write: if member(owner); }
      match /members/{uid} { allow read, write: if isOwner(owner); }
      match /activity/{id} { allow create: if member(owner) && request.resource.data.uid == request.auth.uid; allow read, delete: if isOwner(owner); }
    }
  }
}

            الذكاء الصناعي

            المساعد والتقرير الشهري لا يحتاجان مفتاحاً، فهما يعملان عبر خدمة Cloudflare المجانية بحصة يومية محدودة. المفتاح اختياري ويُستخدم لقراءة الفواتير بدقة أعلى، ويُحفظ على هذا الجهاز فقط، والتكلفة تُحسب على حسابك لدى Anthropic (platform.claude.com).

            مجاني

            اسأل بالعربي عن أرقامك: ربح شهر، أكثر عميل ربحاً، ما الذي لم يُبع بعد، كم طناً اشتريت من مورد… والجواب مبني على بياناتك الفعلية.

            يُرسل ملخص بياناتك (الشحنات والعملاء والموردون والأسعار) مع كل سؤال إلى خدمة الذكاء الصناعي على Cloudflare للرد عليه. حسب سياسة Cloudflare لا تُستخدم هذه البيانات لتدريب نماذجها. الخدمة مجانية بحصة يومية محدودة.

            التقرير الشهري

            تقرير داخلي: كل ما اشتريته وبعته في الشهر، من أي شركة اشتريت، ولمن بعت، مع الأصناف والأوزان والمصاريف والأرباح. لا ترسله للعملاء.

            إبلاغ عن رد غير مناسب أو خاطئ

            تقرير ربح الشحنة

            تقرير داخلي بكل تفاصيل الشحنة: المورّد والعميل والسائق والتكاليف وإجمالي الربح وصافيه. لا ترسله للعميل، وأرسل له الفاتورة الضريبية.

            إضافة

            للشحنة التي تسجّل فيها الأسعار والتكاليف وتصدر لها الفاتورة الضريبية.

            يُصدر قبل الفاتورة، عند تحميل الشحنة، بدون أي أسعار. تقدر لاحقاً تفتحه من القائمة وتكمل الأسعار لتتحول إلى شحنة كاملة.

            تختار رقم الفاتورة الضريبية، فتنتقل أصنافها وأوزان البيع إلى GRN، وتضيف وزن الـ WASTE، ثم ترسله للمورّد الذي اشتريت منه.

            عرض أسعار رسمي للعميل: تعدّل السعر وآلية التسعير والشروط والتاريخ، وتصدره PDF.

            GRN · إشعار استلام البضاعة

            بيانات GRN

            الأصناف والأوزان (طن)

            الوزن الكلي يؤخذ تلقائياً من وزن البيع (بالطن). اكتب وزن الـ WASTE بالكيلو لكل صنف، فيُخصم ويظهر الصافي، مثلاً 15 طن و100 كجم = 14.900 طن. رقم الفاتورة الضريبية لا يظهر في الـ GRN.

            معاينة

            مستند

            إشعار دائن ضريبي

            الإشعار الدائن هو الطريقة القانونية لتخفيض فاتورة صادرة (فرق سعر، نقص وزن، خصم جودة، مرتجع). يُنقص المبيعات والضريبة في الإقرار، ويُنقص ما على العميل.

            معاينة

            اختر دولة شركتك

            يضبط التطبيق الضريبة والعملة والرقم الضريبي وشكل الفاتورة والتقارير حسب قوانين دولتك. تقدر تغيّرها لاحقاً من الإعدادات.

              اختياري: صياغة أذكى بالذكاء الاصطناعي (مفتاح API)
          
              بدون مفتاح يعمل المساعد بالذكاء الصناعي المجاني (Cloudflare)، ويفهم الأصناف والأسعار والعميل والتسليم والدفع من كلامك، حتى لو كتبتها سطراً سطراً. المفتاح اختياري لصياغة أدق.
              
          
              1. افتح platform.claude.com وسجّل الدخول (هذا موقع منفصل عن تطبيق Claude).
              2. من Plans & Billing أضف بطاقة واشحن رصيداً صغيراً (مثلاً 5 دولار). اشتراك Claude العادي لا يشمل الـ API.
              3. من API Keys اضغط Create Key وانسخ المفتاح (يبدأ بـ sk-ant-).
              4. الصقه في الخانة أدناه مرة واحدة، ويُحفظ على هذا الجهاز فقط.
              
          
              تكلفة العرض الواحد صغيرة جداً (سنتات قليلة على الأكثر).
